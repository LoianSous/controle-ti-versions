# Controle TI - Releases

Este repositório é utilizado para distribuição das versões oficiais do Controle TI.

## Como baixar

1. Acesse a aba **Releases**
2. Abra a versão mais recente
3. Baixe o arquivo:

```txt
Controle.TI.Setup.x.x.x.exe
```

## Atualizações automáticas

Após a instalação, o sistema verificará automaticamente novas versões disponíveis e poderá atualizar o aplicativo automaticamente.
